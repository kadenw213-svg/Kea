# Personal config (template)

Copy to `config/personal.local.md` (gitignored, never committed) and fill in.
Skills read values from the local copy by key. Leave a value blank if unused.

- owner_name:            # how skills refer to whose data this is
- institution:           # e.g. "Example State College"
- d2l_home_url:          # real bookmarkable D2L home, e.g. https://d2l.example.edu/d2l/home/1234 (also saved as the d2l_base_url pref)
- d2l_host:              # e.g. d2l.example.edu
- sso_notes:             # e.g. "Banner CAS at cas.example.edu, username + password, Chrome autofills"
- digest_email_to:       # where /daily-overview emails go (also saved as the digest_email_to pref)
